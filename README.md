
# MiniProj1 — Curriculum Vitae SPA

Mini projeto desenvolvido no âmbito da unidade curricular
Programação Web Avançada, do Mestrado em Engenharia
Informática e Tecnologia Web (UAb / UTAD).

## Objetivo

Desenvolver um currículo pessoal numa aplicação Web de
página única (Single Page Application — SPA), utilizando Vue.js.

## Funcionalidades previstas

- Quem Sou Eu?
- O que faço?
- Hobbies
- Navegação sem recarregamento da página
- Rodapé com ligações para redes sociais
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Vue.js

## Estado

Projeto em fase inicial de desenvolvimento.
